# Bikcraft - Site de Apresentação de Bicicletas Elétricas
Este é um projeto simples desenvolvido em HTML e CSS para criar uma página de apresentação de bicicletas elétricas da marca Bikcraft. O site tem um design moderno e responsivo, com informações sobre os produtos, vantagens e detalhes da bicicleta.

## Funcionalidades
Menu de navegação: O menu possui links para seções como Sobre, Produtos, Lojas e Contato.
Introdução: Exibe um título e uma breve descrição sobre a bicicleta da marca Bikcraft.
Vantagens: Lista os principais benefícios da bicicleta, como motor elétrico, velocidade de 40 km/h e sistema de rastreamento.
Rodapé: Contém a mensagem de direitos autorais da Bikcraft.
